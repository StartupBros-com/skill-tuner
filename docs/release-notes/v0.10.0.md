# skill-tuner v0.10.0

Portfolio mode (issue #57): the "should the model start this at all?" question, asked across every skill an agent carries instead of one document at a time.

## Highlights

- `/skill-tuner:portfolio` lists every skill and command the model is shown (yours, claude.ai-synced skills, the project's, every enabled plugin's) with what each costs on every turn, how often it is used, and which setting decides whether the model sees it, then walks the costliest ones with you one at a time.
- The first question for each skill is whether the model should start it on its own; a skill that acts in your name is `/`-only by nature, which removes its cost and every misroute at once. Only skills that stay visible get description work, through `/skill-tuner:tune`.
- Usage counts inform the walk and never decide it, and nothing is changed without your answer for that skill. A project skill's count includes the uses Claude Code records under its worktree copies.
- Plugin skills have no per-skill switch in Claude Code; the report shows, per plugin, what turning the whole plugin off for one project would save.
- `tune.py portfolio` makes no model calls, reads files only, and names every source it could not read.
